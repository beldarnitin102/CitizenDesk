# 🏛️ CitizenDesk: AI-Powered Smart District Complaint Management System

[![Node.js](https://img.shields.io/badge/Node.js-99.7%25-green.svg)](https://nodejs.org/)
[![Deployment](https://img.shields.io/badge/Deployment-Live-success.svg)](https://citizen-desk-seven.vercel.app)


Traditional grievance redressal systems often rely on manual complaint categorization and department assignment, resulting in delayed resolutions and inefficient administration. **CitizenDesk** is an intelligent, AI-powered platform designed to automate complaint processing using advanced language understanding, computer vision, and predictive analytics.

---

## ✨ Key Features

* **🌍 Multilingual Support:** Citizens can submit complaints in multiple regional languages.
* **📂 Multimodal Submissions:** Upload text, images, videos, documents, and precise location details.
* **🤖 Automated Processing:** 
  * Intelligent categorization and priority prediction.
  * Automatic routing to the appropriate department.
  * Duplicate complaint detection to eliminate redundancy.
* **💬 Multilingual Virtual Assistant:** Enables citizens to track status updates and receive guidance throughout the resolution lifecycle.
* **📊 Role-Based Dashboards:**
  * **Citizens:** Seamless tracking and submission interface.
  * **Department Officials:** Dedicated dashboards to manage and resolve grievances efficiently.
  * **Administrators:** Deep insights into complaint trends, departmental efficiency, geographic hotspots, and predictive analytics reports.

---

## 🛠️ Tech Stack

* **Frontend:** JavaScript, HTML/CSS (`frotend/`)
* **Backend:** Node.js / Express (`backend/`)
* **AI / ML Integration:** Natural Language Processing (NLP), Computer Vision, and Speech Recognition Specially grok and cohere model is used

Getting Started
Prerequisites
Ensure you have the following installed on your local machine:

Node.js (v16+ recommended)

npm (Node Package Manager)

Installation & Setup
Clone the repository:

Bash
git clone [https://github.com/beldarnitin102/CitizenDesk.git](https://github.com/beldarnitin102/CitizenDesk.git)
cd CitizenDesk
Setup the Backend:

Bash
cd backend
npm install
# Configure your environment variables if required
npm start
Setup the Frontend:

Bash
cd ../frotend
npm install
npm run dev
